# Приёмка комнаты

Как гонять: инструмент комнаты получает файлы из `input/` примера и выдаёт
результат. Результат сверяется с `expected.md` **по смыслу**: формулировки
свободные, факты (кто · что · когда · числа) должны совпасть. Итог демо:
«прошло N из M».

Примеры синтетические, собраны по мотивам болей заказчиков комнаты.
Реальные тексты болей в репозиторий не публикуются.

Канон для всех примеров — `canon.md`. Меняется канон — меняется поведение
конвейера, без правки кода.

## Дополнительные задания

`04-ai-practiq-content/` — supplemental-набор из трёх публичных статей AI
Practiq, редакционного брифа и критериев для сценариев рилзов и дайджеста.
Полные тексты статей не копируются. Текущая автоматическая приёмка команды
обрабатывает только канонические примеры 01–03; новый набор станет частью
приёмки только после отдельного решения комнаты и обновления конвейера.
