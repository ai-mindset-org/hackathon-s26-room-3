# Ожидаемый сценарий рилза (30 сек)

Структура обязательная:
- **Хук (0–3 с):** цепляющая фраза про боль (потерянный чек / забытая подписка)
- **Суть (3–22 с):** что делает продукт, 2–3 факта из заметок (3 подписки,
  2 минуты настройки, любая почта)
- **CTA (22–30 с):** одно конкретное действие

Канон соблюдён: без эмодзи, без антитез, без запрещённых слов, факты — из
заметок, ничего выдуманного (проверить: цифр, которых нет в заметках, в
сценарии нет).
