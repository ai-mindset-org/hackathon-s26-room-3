# Канон контента (синтетика для приёмки)

1. Без эмодзи.
2. Заголовки со строчной буквы.
3. Запрещена антитеза «не X, а Y» и её вариации («это не X — это Y»).
4. Запрещённые слова: «уникальный», «инновационный», «прорывной», «синергия».
5. Абзац ≤ 4 строк. Пост ≤ 1200 знаков.
6. Каждое утверждение с числом — с указанием источника в скобках.
7. Пост заканчивается одним конкретным действием для читателя (CTA), без «подписывайтесь».
8. Тон: разговорный, на «вы», без канцелярита («осуществлять», «данный», «в рамках»).
