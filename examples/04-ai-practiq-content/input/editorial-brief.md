# Редакционный бриф AI Practiq

Статус: supplemental-задание для комнаты. Этот файл задаёт контекст поверх
трёх сокращённых источников и не заменяет общий `examples/canon.md`.

## Зачем существуют статьи

### Клубный блог

Статьи на Sostav и других площадках работают как SEO-вход в воронку:

`поисковый трафик → подписка на Telegram-канал → покупка курса Claude Code`.

Канал — основной актив, курс — точка монетизации. Claude Code используется как
тема с поисковым спросом, но идентичность AI Practiq — сообщество
предпринимателей, внедряющих ИИ, а не только курс по одному инструменту.

Каждая статья должна опираться на реальный кейс участника клуба и показывать
конкретный результат без преувеличений. Для публикаций клубного блога
предпочтительный CTA — одно конкретное действие: перейти в Telegram-канал.

### Личный блог и GEO

Это отдельная цель. Сначала личный блог должен стать источником по теме
«предприниматель внедряет ИИ» без упоминания клуба. Позже отдельный материал о
выборе AI-сообщества может приводить AI Practiq в ответах ChatGPT, Perplexity,
Gemini и Алисы.

Не смешивать эти две стратегии в одном результате: материалы из этого набора
относятся к клубному блогу и SEO-воронке.

## Задание агенту

Используя три источника и общий канон, подготовить:

1. По одному сценарию рилза на каждый источник.
2. Один дайджест по всему набору статей.

Сценарии и дайджест должны быть пригодны для дальнейшей ручной проверки
заказчиком. Не добавлять внешние ссылки, цифры, кейсы или обещания, которых нет
в источниках и этом брифе.

## Ограничения

- Не выдавать Claude Code за единственную суть AI Practiq.
- Не утверждать, что статьи сами по себе гарантируют рост подписок.
- Не подменять конкретные кейсы общими фразами про «революцию ИИ».
- Соблюдать все правила `examples/canon.md`.
