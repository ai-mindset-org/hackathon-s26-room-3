# Ожидаемый отчёт вычитки

Нарушения (минимум эти):
1. Эмодзи в заголовке (п.1)
2. Заголовок с заглавных (п.2)
3. «Это не просто X, а Y» — антитеза (п.3)
4. «Уникальный», «прорывной», «синергия» (п.4) — три слова, каждое названо
5. «В рамках», «осуществляется» — канцелярит (п.8)
6. «на 40%» без источника (п.6)
7. CTA «подписывайтесь» (п.7)

Плюс переписанный черновик, где всё это устранено. Ключевая проверка:
каждое нарушение названо с номером пункта канона и точным местом.
