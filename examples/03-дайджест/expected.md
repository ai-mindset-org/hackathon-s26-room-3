# Ожидаемый дайджест недели

- Формат: заголовок со строчной, 3–5 пунктов, каждый ≤ 2 строк
- Вошло: тёмная тема · 120 регистраций (с оговоркой про лендинг) · саппорт 6ч→2ч
- Срыв интеграции — упомянут честно (плохие новости не прячутся)
- «Внутренний спор про цену» — НЕ вошёл (не событие для читателя) либо вошёл
  как «решение по цене ожидается» — оба варианта зачёт
- Канон: без эмодзи, числа с источником не нужны (источник — сами заметки),
  антитез нет
