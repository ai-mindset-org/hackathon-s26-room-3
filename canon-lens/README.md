# canon-lens

Модуль участника **HA59**. Папка изолирована: зависимостей от других модулей нет,
входы (`canon.md`, текст) уже существуют, выход самодостаточен.

## Что делает

Детерминированная проверка текста против **канона-файла**. На каждое нарушение —
запись с точным местом (строка, колонка, абсолютный сдвиг), цитатой, номером
пункта канона и подсказкой правки.

Канон — данные, не код (`canon.md`, машинный блок ` ```toml `). Меняешь канон →
меняется поведение. Кода трогать не нужно.

Смысловые правила (вариации антитезы, тон, «событие ли это для читателя») здесь
ловятся **только в буквальной форме** и помечаются `kind: judgment-literal` —
вариации добирает модуль `judge/` в той же форме записи.

## Запуск

```bash
python -m canon_lens.cli check <файл> [--canon canon.md] [--json]
# из корня репозитория:
python canon-lens/tests/test_example01.py      # мини-тест приёмки, одна строка PASS/FAIL
```

Код возврата `check`: `1` если есть нарушения `severity=error`, иначе `0`.

Зависимости: только стандартная библиотека Python ≥ 3.11 (`tomllib`).

## Покрытие правил synthetic-канона (`examples/canon.md`)

| п. | правило | как | тип |
|---|---|---|---|
| 1 | без эмодзи | диапазоны Unicode | механически |
| 2 | заголовок со строчной | первый `#`-заголовок | механически |
| 3 | без антитезы «не X, а Y» | буквальные шаблоны | буквально + `judge/` |
| 4 | стоп-слова | список основ | механически |
| 5 | абзац ≤ 4 строк, пост ≤ 1200 знаков | счёт | механически |
| 6 | число → источник в скобках | число без `(…)` в строке | механически (грубо) |
| 7 | CTA без «подписывайтесь» | список основ | механически |
| 8 | без канцелярита | фразы + основы + формы | механически (список) + `judge/` (тон) |
| — | **redaction** | пути, токены, e-mail | механически (безопасность публикации) |

## Границы

- «данный» проверяется точными формами без `данные/данных/данными` (коллизия со
  словом «данные»). Полный разбор — задача `judge/`.
- `number_without_source` — эвристика: источник = скобка `(…)` в той же строке.
  Годы (4 цифры) пропускаются.
- Прозаический фолбэк-парсер (`examples/canon.md` без toml-блока) — best-effort.

## Контракты
