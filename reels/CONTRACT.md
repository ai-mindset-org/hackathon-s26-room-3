## шов

```
сырьё (статьи, заметки) --[экстрактор]--> facts.json --[сборщик]--> script.md + report.md
                                                        canon.md ----^
```

Шов выбран под приёмочный пример `02-рилз`: его ключевая проверка — «цифр,
которых нет в заметках, в сценарии нет». Экстрактор эту проверку и
гарантирует: если он отдаёт только найденное в тексте, сборщик физически не
может выдумать число.

## facts.json — формат

```json
{
  "source": {
    "id": "86369",
    "title": "заголовок статьи",
    "origin": "путь к файлу или url",
    "chars": 12400
  },
  "facts": [
    {
      "id": "f1",
      "kind": "number",
      "text": "средний пользователь находит 3 забытые подписки в первый месяц",
      "value": "3",
      "unit": "подписки",
      "quote": "дословный фрагмент исходного текста, из которого взят факт"
    },
    {
      "id": "f2",
      "kind": "claim",
      "text": "работает с любой почтой",
      "value": null,
      "unit": null,
      "quote": "дословный фрагмент"
    }
  ]
}
```

Поля обязательные все. `kind` — одно из `number`, `claim`, `quote`, `entity`,
`action`. `value` и `unit` заполняются только при `kind: number`, иначе `null`.

**Главное правило экстрактора:** в `text` не может быть ничего, чего нет в
`quote`. Пересказ разрешён, добавление — нет. `quote` берётся из исходника
посимвольно.

**Главное правило сборщика:** в сценарий попадают только факты из массива, по
их `id`. Ни одного числа, слова или утверждения помимо них.

## выход сборщика

`reels/out/<source.id>/script.md`:

```markdown
# сценарий: заголовок со строчной буквы

## хук (0–3 с)
одна фраза про боль

## суть (3–22 с)
2–3 факта

## cta (22–30 с)
одно конкретное действие

## использованные факты
f1, f2, f5
```

`reels/out/<source.id>/report.md`:

```markdown
# отчёт

## нарушения канона в исходнике
1. п.4 «уникальный» — «дословное место»
2. п.3 антитеза — «дословное место»

## факты вне источника
нет

## решение
годится
```

## право промолчать

Сборщик обязан уметь ответить отказом. Тогда `script.md` не создаётся вовсе,
а в `report.md` раздел `## решение` содержит `контента нет` и причину одной
строкой. Это часть контракта, а не опция: инструмент, который выдаёт сценарий
на любое сырьё, — генератор шума.

## интерфейс запуска

Python 3, только стандартная библиотека, чтобы лидер комнаты мог подключить
куски к своему CLI без установки зависимостей.

```bash
python -m reels.extract <входная-папка> -o reels/out/<id>/facts.json
python -m reels.compose reels/out/<id>/facts.json examples/canon.md -o reels/out/<id>/
```

Оба возвращают код 0 при успехе. `compose` возвращает 0 и при отказе:
отказ — это штатный результат, а не ошибка.

## фикстура вперёд кода

Первый коммит каждого — пример своего выхода, написанный руками, а не код.

- `meta1ex` кладёт `reels/fixtures/facts.example.json` в первые пять минут.
  С этой минуты сборщик работает на нём и не ждёт готового экстрактора.
- `tonclap` кладёт `reels/fixtures/script.example.md` и `report.example.md`.
  Экстрактор видит, какие поля реально нужны на том конце.
