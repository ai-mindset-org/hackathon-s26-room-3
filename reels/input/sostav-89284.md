Андрей Богомолов — 5 кейсов вайбкодинга с Claude Code на встрече AI Practiq Club

Андрей Богомолов — сооснователь GenAI Lab, 10+ лет в искусственном интеллекте. Консалтил Johnson & Johnson, Mars, другие крупные компании. До этого — сооснователь стартапа, который поглотил Мегафон. Код руками не писал больше пяти лет.

В марте 2026 года он пришёл на закрытую встречу AI Practiq Club и показал пять кейсов — каждый сделан через вайбкодинг, без единой строчки кода, написанной вручную. Презентацию к встрече, кстати, тоже завайбкодил.

Ниже — все пять примеров с деталями.

## Что такое вайбкодинг

Термин придумал Андрей Карпати (один из основателей OpenAI) в начале 2025 года. Идея простая: объясняешь AI, что хочешь получить — AI пишет код. Смотришь на результат, говоришь что поправить — AI правит. В сам код можно не заглядывать вообще.

По данным Stack Overflow Developer Survey 2025, 84% разработчиков уже используют или планируют использовать AI-инструменты в работе. Но вайбкодинг — это шире. Им занимаются люди, которые никогда не программировали: маркетологи, предприниматели, консультанты. Андрей — один из них.

Во всех пяти кейсах инструментом был Claude Code — AI-ассистент для разработки от Anthropic, работает прямо в терминале.

## Кейс 1: Лендинг за 15 минут

Андрей хотел проверить: можно ли через Claude Code делать визуально приличные сайты? Раньше лендинги такого уровня заказывали у студий — за 300 тысяч рублей и несколько недель согласований.

Он использовал два инструмента. Первый — Frontend Design Skill, плагин для Claude Code, который улучшает визуальное качество генерируемых интерфейсов. Второй — библиотека Framer Motion для анимаций. Названия библиотеки Андрей не знал — просто услышал где-то и сказал Claude: «Разберись и применяй».

Лендинг SYNTH — полный цикл AI-трансформации, создан за 15 минут через Claude Code вайбкодинг

Два промпта. 15 минут, пока пил утренний кофе. На выходе — лендинг с плавными анимациями, ховер-эффектами, прокруткой и формами. Андрей честно признаётся: за такой сайт он бы сам заплатил деньги, если бы Claude Code не существовал.

Потом показал лендинг на звонке — и сразу задеплоил в онлайн. Деплой тоже сделал Claude: прописал домен в Cloudflare, настроил сервер. «Говорю — залей на сервак, привяжи домен. Он разбирается.»

## Кейс 2: Мини-игра для Burger King с одного промпта

Человек из команды Burger King (занимается промо-проектами для бренда) спросил Андрея: можно ли сделать простую браузерную игру в стилистике BK?

Задача: «залепательная» игра, где нужно ставить блоки друг на друга — как в классической Stack, только забрендированная. Логотипы Burger King, фирменные цвета, анимации.

Андрей скормил Claude Code бренд-бук Burger King, скриншоты референса и ссылку на проект-донор. Сказал: «Делай анимации сам, всё сам делай, справляйся».

Браузерная игра Burger King Runner — создана с одного промпта через вайбкодинг с Claude Code

Результат — с одного промпта. Рабочая игра с анимациями, иконками, счётом. Логотипы на фоне получились немного корявые (AI-генерация), но механика работала полностью. Второй промпт — «залей на сервер и привяжи домен».

Для команды Burger King такие мини-игры вешают на страницу 404 или используют в промо-акциях. Раньше на подобное уходили дни работы разработчика.

## Кейс 3: Telegram-бот с оплатой — 50 000 строк кода, ноль багов

Это кейс, которым Андрей гордится больше всего.

Виктор Савюк (создатель Dindi) попросил сделать Telegram-бота для своей жены Алёны — эксперта по медитациям. Изначальная задача: простой бот с двумя функциями — поиск по статьям и рассылка расписания медитаций.

По ходу работы Андрей увлёкся. Появился полноценный мини-апп в Telegram.

Что внутри: онбординг с диагностикой и персональным подбором программы, ежедневные практики с плеером и прогресс-барами, бонусные медитации, оплата через Робокассу (живые деньги, ни один платёж не потерялся), push-уведомления. Вся визуальная часть — дизайн от Claude Code (Frontend Design Skill), без дизайнера.

Telegram mini-app с оплатой — 50 000 строк кода, сделано через вайбкодинг с Claude Code без программиста

50 000+ строк кода. Андрей не написал ни одной строчки. Продукт вышел в прод, принимает реальные платежи, работает без сбоев.

Когда Андрей раньше делал похожие проекты с командой разработчиков (бэкенд, фронтенд, DevOps) — багов было больше. Здесь — ноль.

Как он управлял проектом: через папку docs/feature-request/ складывал спецификации новых фич (надиктовывал голосом), в CLAUDE.md прописал процесс разработки — тестировать через Playwright, обновлять архитектуру, прогонять линтеры. Claude Code сам вёл файл архитектуры проекта, чтобы сохранять контекст между сессиями.

«Общение с этой штукой похоже на работу с командой разработки. Ставишь задачи, формулируешь, получаешь результат. Только итерация занимает 15 минут, а не три дня»

## Кейс 4: 500 Telegram-каналов за 40 минут

Кто-то в чате клуба спросил: как найти Telegram-каналы на определённую тематику? Андрей подумал — а справится ли Claude Code?

Раньше у его команды была похожая задача: искали каналы для закупки рекламы под вебинары. Ручная работа — долгая и муторная.

Андрей дал Claude Code задачу: найти каналы по теме искусственного интеллекта. Claude работал 40 минут автономно — искал в каталогах, парсил данные, проверял актуальное количество подписчиков для ранжирования.

Парсинг 500 Telegram-каналов: ChatGPT — советчик, Claude Code — исполнитель. Вайбкодинг пример

Результат: ~500 каналов. Примерно 100 оказались не совсем по теме — около-IT. Остальные 400 — в точку.

Для сравнения: Андрей попробовал ту же задачу через ChatGPT. Ответ: «Вот тебе Python-скрипт, запускай сам, ставь библиотеки». Claude Code принёс готовый список. Человек на такую задачу потратил бы полный рабочий день — и к двухсотому каналу скорее всего сдался бы.

## Кейс 5: Воскрешение мёртвого продукта — 40 микросервисов за три вечера

К Андрею пришли бывшие коллеги: нужно срочно поднять продукт, который не работал три года.

Контекст: продукт из предыдущего стартапа Андрея, который поглотил Мегафон. После поглощения всё закрыли, серверы выключили, команда разбежалась. Прошло шесть лет с момента разработки.

Что досталось Андрею: жёсткий диск с единственным экземпляром кодовой базы. 40 микросервисов. Стек: Python, PHP, Node.js, C++. Документации — ноль. Полтора терабайта данных.

Его метафора для задачи: «Представьте, что всю мебель Букингемского дворца разобрали на детали, свалили в одну кучу, часть деталей потеряли, часть лишних добавили — и сказали: собери как было.»

Сначала он нанял DevOps-инженера. Тот бился три недели — поднял 2 сервиса из 40 (базу данных и фронтенд). Потом Андрей поймал его на том, что тот врал о прогрессе.

Тогда подключил Claude Code. Воткнул жёсткий диск, скормил остатки документации (две страницы), сказал: «Разбирайся и поднимай».

Результат вайбкодинга: DevOps 3 недели — 2 из 40 сервисов, Я + Claude Code 15 часов — 40 из 40

За три вечера по пять часов (~15 часов) — все 40 микросервисов подняты. Андрей в это время фоново смотрел YouTube и слушал музыку, пока Claude Code по 40 минут непрерывно крутил задачи.

Заказчик был в восторге. Андрей рассказал ему, что «работала целая команда». По факту — он и Claude Code.

## Что Claude Code дал во всех пяти кейсах

Андрей работает с Claude Code в терминале — даже не в VS Code. Все задачи надиктовывает голосом. По его словам, это похоже на работу с командой разработки: те же формулировки, те же итерации, только результат приходит за минуты.

Вайбкодинг меняет не только скорость, но и ощущение от работы. Психической энергии тратишь меньше. Работа перестаёт раздражать.

Исследование GitHub и Microsoft Research (2023) показало, что с AI-ассистентом задачи выполняются на 55% быстрее — 1 час 11 минут против 2 часов 41 минуты. У людей без технического бэкграунда, как Андрей, разница ещё больше: без AI они бы эти задачи просто не сделали.

Что конкретно даёт Claude Code в этих кейсах:

- Работает с файловой системой проекта, видит всю структуру кода
- Контекстное окно до 1 млн токенов — удерживает в памяти большие проекты
- Умеет деплоить, настраивать серверы, работать с API
- Поддерживает MCP — подключение внешних инструментов (Figma, базы данных, браузер)
- Ведёт архитектуру проекта между сессиями через CLAUDE.md и docs

## Частые вопросы о вайбкодинге с Claude Code

Нужно ли уметь программировать, чтобы начать вайбкодинг?

Нет. Андрей Богомолов не писал код руками больше пяти лет — и создал продукты с 50 000+ строк кода. Вайбкодинг строится на умении чётко ставить задачу и проверять результат, а не на знании синтаксиса.

Насколько реален вайбкодинг для бизнес-задач — не учебных примеров?

Все пять кейсов из этой статьи — реальные продукты: лендинг с деплоем, игра для бренда, Telegram-апп с живыми платежами, парсер каналов, поднятый сервис из 40 микросервисов. Всё принято заказчиками или используется в работе.

Что делать, если Claude Code ошибается?

Даже Андрей признаёт, что AI иногда делает корявые вещи — например, логотипы в кейсе с Burger King получились не идеальными. Подход тот же, что с любым подрядчиком: говоришь что не так — он правит. Несколько итераций обычно дают результат.

Чем вайбкодинг с нуля отличается от использования ChatGPT?

ChatGPT работает в чате и не имеет доступа к файловой системе. Claude Code видит весь проект, запускает команды, деплоит, тестирует. В четвёртом кейсе: ChatGPT дал Python-скрипт для самостоятельного запуска, Claude Code принёс готовый список каналов.
