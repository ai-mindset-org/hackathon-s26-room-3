Что дальше у меня:

- `reels/extract/__main__.py` — извлечение через `claude -p`, но с машинной

- прогон по всем трём статьям → `reels/out/<id>/facts.json`.

Замер, из-за которого не беру чистые regex: на три статьи 56 предложений с
цифрами и ещё 47 — с числительными словами («две недели», «за три дня»).
У статьи `97142` цифровых предложений всего 8, а заглавный факт «ERP за три
дня» — словами. Regex потерял бы почти половину фактуры.

Интерфейс — stdlib, без установки зависимостей:

```bash
python -m reels.extract reels/input/sostav-86369.md -o reels/out/86369/facts.json
python -m reels.extract reels/input/ -o reels/out      # все три разом
```

Если у лидера комнаты нет бинарника `claude` — режим `--no-llm` даёт
обеднённую выдачу (только предложения с цифрами), но не падает.
